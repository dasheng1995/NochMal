# 德词轮刷 · NochMal

**中文名：** 德词轮刷  
**英文名：** NochMal  
**版本：** 1.1  

NochMal（德语「再来一次」）是一款面向中文用户的 **Android 德语词汇轮刷工具**：用高频词库 + 选择题冲量练习，帮你在短时间内反复过词，而不是拉很长间隔的传统 SRS。

## 为什么做这个 App

背德语单词时，常见矛盾是：

- Anki 等间隔重复很稳，但**单日吞吐偏低**，冲 A1–B2 词量时节奏慢；
- 纯列表死记缺少**即时对错反馈**和**词义场景**；
- 手机上需要**离线可用**、词库可按等级拆分安装，避免安装包过大。

因此 NochMal 的目标是：

1. **高吞吐刷词**：选择题（看词选义）为主，选对进释义，选错标红可继续；
2. **按库隔离**：A1 / A2 / B1 / B2 各自进度（斩 / 未看过 / 不会 / 学习中 / 第几轮）；
3. **斩（Easy）雪藏**：会的词下一轮不再出现；
4. **瘦 App + 外置词库包（`.deword`）**：App 本体轻量，词库（音频 + 强压缩配图 + 中英释义）按需导入。

## 从旧版升级（保留进度）

进度按「等级 + 单词 id」存在 App 私有目录，**与词库文件分开**。按下面做一般可保留斩 / 不会 / 学习中 / 轮次。

### 1）更新 App（APK）

1. 下载 `NochMal-1.1.apk`
2. **直接覆盖安装**（不要先卸载 App）
3. 打开确认版本为 **1.1**

> 先卸载会清空本地进度，请勿卸载。

### 2）更新词库（`.deword`）

1. 下载需要的 `NochMal-*-1.1.deword` 到手机
2. 打开 **德词轮刷** → **导入词库** → 选中对应文件  
3. 等待提示导入成功即可

**要点：**

- **不要**点「删除词库」后再导入——删除会连该等级进度一起清掉
- 同一等级再导入 = 覆盖词库内容（释义 / 例句 / 音频 / 配图），**已有单词 id 的进度会保留**
- 若新包增加了单词 id，新词会以「未看过」出现；旧词进度不动

建议：先覆盖安装 APK，再按需重新导入 A1–B2 词包。

## 1.1 更新日志

### 优化

- 首页全库搜索：搜索中顶栏返回、输入框清空（×）；返回键 / 系统后退会清空搜索框
- 刷词进度条：按「（词库总数 − 未看过）/ 词库总数」显示总进度；已斩词计入已完成（相当于每轮都看过）
- 选择题 / 释义展示：选择题中文最多 2 个义项 + 英文；释义页展示词性、德语助手中文全义 + 英文释义
- 选对 / 选错增加简洁提示音（选对为短音效，选错为系统提示音）
- A1–B2 词库中文释义按**本地德语助手**词典重新核对写入（`def_zh` / `def_zh_full`）

### 修复

- 同一轮中途退出再「开始刷词」时，已刷过的词会再次入队的问题（现按本轮 `passCount` 排除）
- 德语助手匹配误命中复合词尾巴 / 噪声条目（如 Motor → 错误中文）的问题，已收紧边界与打分并重打包

### 说明（未改动的已知限制）

- 词库配图仍为自动检索，**未经人工逐条筛选**，可能与词义不完全对应
- 选择题只取主要义项，可能与例句用法不完全一致，可结合其他词典

### 词库配图说明

词库包内的释义配图由自动化流水线按词义检索（Pixabay / Wikimedia 等）并强压缩写入 `.deword`，**未经人工逐条筛选**。因此可能出现图文不完全对应、偏题或质量参差等情况；刷词时请以中英释义与例句为准，配图仅作辅助记忆。

### 释义与例句说明

- **双语辅助：** 词义与例句均提供中文、英文。有一定英语基础时，可对照英文把德语意思钉得更准。
- **义项取舍：** 选择题最多约两个主要中文义项；释义页展示德语助手中的更完整中文义 + 英文。若与例句场景不完全一致，建议再查其他词典。

## 安装与运行环境

### 手机要求

- **系统：** Android 8.0（API 26）及以上
- **架构：** 常见 ARM64 手机即可
- **权限：** 需允许「安装未知应用」/ 侧载 APK；导入词库时使用系统文件选择器读取 `.deword`
- **网络：** **刷词全程可离线**；仅在你自行跑词库构建脚本拉图时才需要网络与 API Key（Keys 不随仓库分发）

### 全新安装

1. 从 Release 下载 `NochMal-1.1.apk` 并安装
2. 下载需要的 `.deword` 到手机
3. 打开 **德词轮刷** → **导入词库** → 选中对应 `.deword`
4. 进入词库 → **开始刷词**

### 自行编译 App（可选）

- JDK **17**
- Android SDK（compileSdk 35）
- 在 `app/` 目录执行：`.\gradlew.bat assembleDebug`
- 产物：`app/app/build/outputs/apk/debug/app-debug.apk`

## 安全说明

- 仓库**不包含** Pixabay / Pexels 等 API Key。
- 词库构建如需 Key，请本地复制 `a1-b2/packs/image_api_keys.example.json` 为 `image_api_keys.json`（已 gitignore）。
